02 · Engineering / simulation

Heloria Sim

An open-source high-power rocket flight simulator. It flies one design through three independent engines (OpenRocket, RocketPy and a built-in physics model), flags where they disagree, then flies it thousands of times with randomised weather, build and motor variation.

  • Built for Heloria v8, a 29 mm minimum-diameter rocket: the engines agree on Mach 1.45–1.47 and about 2,940–3,000 m apogee
  • Monte Carlo over wind, gusts, rail tilt, temperature, mass, thrust and drag, with every flight exported as CSV, JSON and HTML
  • Streamlit web app with simple and advanced design modes that works on a phone, plus a CLI and Python API
  • Python
  • Streamlit
  • RocketPy
  • OpenRocket (JPype)
  • NumPy
