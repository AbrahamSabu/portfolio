# GDELT fixtures

Cut from the GDELT Project's 15-minute batch of 2026-10-30 12:15 UTC
(https://www.gdeltproject.org/, free for any use with a citation): nine
articles (six political, three not) with only the columns the parser reads,
their events, and 41 country-level events for country names. The zips hold
the same files, as GDELT ships them; `stored-with-comment.zip` is a
hand-made uncompressed archive with a comment, for the zip reader.
