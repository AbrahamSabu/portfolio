Heloria Sim

An open-source rocket flight simulator that flies one design through three independent engines (OpenRocket, RocketPy and a built-in physics model), shows where they agree, and runs thousands of randomised flights to see how a design holds up.

Get the code Run your own copy

What it does

Three engines, one answerThe same rocket goes through OpenRocket, RocketPy and a built-in model. You get each result, the average, and a flag wherever they disagree.
Simple or advanced designSwap real parts from a catalogue, or edit every dimension, material, fin shape and mass, with a live true-scale drawing.
Thousands of flightsMonte Carlo runs vary wind, gusts, temperature, build weight, motor thrust and drag, then let you explore what drives the result.
All the dataDownload every flight, full time series, percentiles, plots and a report as CSV, JSON and HTML.

Built for a real rocket

I wrote it while designing Heloria v8, a 29 mm minimum-diameter rocket aiming for Mach 1.2 or more. On that design the engines agree closely:

Tech

Python, Streamlit, Altair, NumPy, RocketPy, and OpenRocket through its Java API (JPype). GPL-3.0 licensed.
